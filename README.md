# Gazette du Bois 🪵

Blog statique des métiers du toit et du bois — charpente, couverture, zinguerie, menuiserie, construction bois, étanchéité, photovoltaïque. Focus Auvergne-Rhône-Alpes.

## Articles

1. **L'intelligence artificielle dans le BTP : de la théorie à la pratique** — parcours « Les Routes vers l'IA » de la CMA AURA, applications concrètes, enjeux pour les artisans.
2. **Crise énergétique : comment les artisans du BTP font face** — impacts (carburant, ateliers, matériaux, séchage du bois) et pistes d'action.
3. **Canicule et chantiers : survivre aux fortes chaleurs sur les toits** — enquête CAPEB, arrêtés préfectoraux, bonnes pratiques.
4. **Label EPV : l'État distingue les savoir-faire d'excellence du bois et du toit** — le label Entreprise du Patrimoine Vivant pour la charpente, la couverture patrimoniale et l'ébénisterie.
5. **Facturation électronique : ce qui change pour les artisans du BTP** — calendrier, plateformes, webinaires d'accompagnement CMA AURA.
